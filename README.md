# Apprentissage

Mon parcours pour apprendre à coder : **HTML, CSS, JavaScript, Python, Rust**.

Chaque dossier `NN-nom/` est un exercice que j'ai écrit moi-même. Mon agent-prof me guide et me corrige ; ce dépôt montre ma progression au fil des sessions.

## Contenu

- `PLAN.md` — le plan complet des 16 modules
- `01-bonjour/` — Module 1 : ma première page web (HTML)
- `01-bonjour/progression/suivi.md` — mon suivi de progression, session par session
- `01-bonjour/progression/couleurs.md` — mes notes de cours sur les couleurs CSS

## Suivre ma progression

À chaque session, je publie mes exercices ici avec git. Le fichier `suivi.md` indique où on s'est arrêté.
